# sentraID
sentraID is a lightweight Linux authentication log monitoring and detection tool.<br/><br/>

It monitors:<br/>
Red Hat-based systems: /var/log/secure<br/>
Debian-based systems: /var/log/auth.log<br/><br/>

# Features
It detects four security events:<br/>
invalid_user<br/>
brute_force<br/>
success_after_failure<br/>
root_login<br/>
